智汇笔记源代码与实现说明交付包

内容：
- backend：Flask REST API、SQLAlchemy 模型、业务服务和 pytest 测试
- frontend：Vue 3 源码、组件、页面、构建配置和 Playwright 测试
- docs：项目文档、测试证据和《智汇笔记系统实现说明》
- scripts、setup.ps1、start-demo.ps1、启动/停止批处理：运行与交付辅助
- frontend/dist：当前构建产物
- backend/demo.db：演示数据库，不含个人生产数据库和真实 AI Key

本包为源码交付包，未包含便携 Python 运行时、离线 wheels、视频/PPT 和嵌套发布 ZIP。需要一键离线运行时，请使用同目录的“智汇笔记-一键启动版.zip”。
