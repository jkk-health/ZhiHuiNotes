# 智汇笔记 软件开发流程架构书

## 系统范围

系统面向学生管理个人信息，提供笔记、待办、思维导图、轻记账、AI 摘要和标签。采用账号隔离数据，业务通过 REST API 提供。保留富文本，marked 只用于旧 Markdown 兼容。

## 技术与分层

Python 3.11 / Flask / SQLAlchemy / SQLite；Vue 3 Composition API / Vite / Bootstrap 5 / Quill 2.0.2 / marked / DOMPurify / jsMind 0.9.1 / ECharts 6.1.0。业务层负责正文规范化、导图转换、AI 降级；接口层负责认证、验证和资源操作。后端同时托管 frontend/dist，不使用服务端页面模板。

浏览器 → Vue 单页 → /api JSON 接口 → SQLAlchemy → SQLite。AI 仅由后端访问外部服务。

## 数据模型

八张表：user、notebook、note、tag、note_tag、todo、mindmap、bill。用户拥有各类业务资源；笔记本删除后笔记归入未分组；标签和笔记通过关联表建立多对多关系。

content_html 保存清理后的富文本，提交 HTML 时由后端生成 content_md 纯文本副本。只有 content_md 的旧笔记仍按 Markdown 兼容。没有重命名字段或清空旧库。

待办和导图通过可空 note_id 关联来源笔记。笔记软删除后关联数据保留，来源标记为在回收站；恢复笔记后恢复跳转。导图不回写笔记。本版本不开放永久删除。

## 接口和关键规则

完整契约见《07-系统设计报告》。所有新增接口要求登录，资源访问按 user_id 限制。无会话 401、他人资源 404、参数错误 400，错误使用 JSON error 字段。

AI 先预览后采用：摘要复制，标签选中后合并。无 Key、本地超时、远程错误或无效结果均降级；总等待最多8秒，远程不重试。返回 engine、reason（仅本地）和 input_truncated。

笔记转导图按 h1/h2/h3 提取层级，根节点使用笔记标题。跳级挂到最近的浅层节点；没有标题时只生成根节点。导图以 node_tree 对象传输，数据库保存 JSON 文本，节点 ID 唯一，最多1000节点、64层。

金额由 Decimal 计算，必须为正数、最多两位小数，不超过99999999.99。月份使用 YYYY-MM，统计按账目日期归属，缺失日期补零。

## 流程和质量门槛

M0环境基线 → M1笔记完善 → M2待办 → M3导图 → M4 AI与记账 → M5交付。任务书是唯一进度清单。每次变更应同步接口说明、测试和负责人；日常合入保持主干能运行。

图源见 diagrams/智汇笔记.drawio、diagrams/智汇笔记.mdj。自动证据见 evidence/；人工验收单独执行，不将自动化记录填写为成员手工签字。
