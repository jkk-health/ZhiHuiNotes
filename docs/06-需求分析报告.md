# 智汇笔记 需求分析报告

## 项目目标

智汇笔记用于学生个人信息管理，在网页内完成课程笔记、行动计划、结构梳理和日常收支记录。系统的核心价值是同一篇笔记可关联待办、生成导图，并借助摘要和标签帮助整理。

需求来源为本项目功能说明和小组课程目标。当前没有用户访谈、问卷样本或定量竞品实验，因此本报告不将需求设想写成已验证的市场结论。

## 用户与使用场景

未登录用户可注册或登录；登录用户只能访问自己的信息。典型场景包括记录课堂知识、为复习内容安排待办、用标题结构形成思维导图、记录生活账目并查看当月变化。断网课程演示仍须展示所有本地功能和AI降级。

## 功能需求

| 编号 | 能力 | 验收行为 |
|---|---|---|
| FR01 | 身份认证 | 注册登录、退出、刷新恢复会话；未登录接口401 |
| FR02 | 富文本笔记 | 创建、查看、修改、软删除、恢复；格式与内嵌图片重开仍在 |
| FR03 | 信息组织 | 笔记本管理、标签管理、标题和正文搜索、置顶 |
| FR04 | 待办 | CRUD、截止日期、完成态、筛选；完成率按当前列表统计 |
| FR05 | 笔记关联 | 从笔记创建待办、两侧跳转、关联和解除；来源删除后仍保留 |
| FR06 | 思维导图 | 标题转换、节点编辑、拖拽、缩放、保存与重新生成确认 |
| FR07 | 轻记账 | 收支管理、月度收入支出结余、每日趋势、分类汇总 |
| FR08 | AI助手 | 摘要、标签建议、先预览再采用、真实API和本地降级 |

## 非功能需求

所有业务数据按用户隔离；密码加盐哈希保存。页面使用Vue单文件组件，业务接口与数据库分层。正文清理、金额验证、日期验证由服务端承担，前端也提供输入限制和提示。静态库从npm打包，演示不依赖CDN。AI远程最多等待8秒，不重试；失败切换本地规则并向用户说明。

未保存的编辑在页面切换时可保存、放弃或取消；网络失败显示错误并保留草稿。浏览器关闭时使用原生离开保护，浏览器不允许网页在关闭时展示自定义三按钮弹窗。

## 范围边界

本轮不开发社区分享、AI问答、独立统计看板、多端实时同步、协作编辑、OCR和移动App。笔记软删除不级联隐藏待办和导图，不开放永久删除；导图编辑不回写笔记。AI候选标签不自动落库，摘要不自动改正文。
