# 智汇笔记 运行与离线交付

## 一键启动（完整交付包）

将 ZIP 完整解压后双击根目录的 `一键启动.bat`。启动器从包内 Python 运行时准备虚拟环境，用 `offline-wheels` 离线安装依赖，仅在缺少 `backend/demo.db` 时创建演示数据；随后启动后台服务，等待服务就绪再自动打开浏览器。无需预装 Python、Node.js 或修改 PowerShell 执行策略。

演示账号为 `demo / demo123456`。重复双击会复用本目录已经运行的服务。默认监听本机 5000 端口，端口被占用时选择 5001～5019。双击 `停止运行.bat` 正常停止服务，数据保留。移动整个文件夹前先停止运行；再次启动会自动修复指向旧目录的虚拟环境。

启动与服务日志保存在 `.tools/launcher/`，后台服务控制只接受本次启动的随机令牌。打包不包含本机虚拟环境、启动状态、日志、数据库和密钥。

## 开发环境

Windows x64、Python3.11、Node20。在项目根目录运行 ./setup.ps1，准备后端环境、安装锁定前端依赖并构建。若Python未被启动器识别，使用 ./setup.ps1 -Python 'Python3.11可执行文件完整路径'。

开发可分别运行后端flask与前端npm run dev。业务接口5000，Vite5173代理/api。首次个人数据库使用backend/.venv/Scripts/python.exe -m flask --app wsgi init-db，在backend目录执行；升级旧库使用upgrade-db，均不清空笔记。

## 独立演示

根目录运行 ./start-demo.ps1，在浏览器打开 http://127.0.0.1:5000 。脚本只在缺少demo.db时初始化，之后使用该独立库。账号demo/demo123456。主动重置仅运行 backend/.venv/Scripts/python.exe backend/seed.py --reset；脚本拒绝app.db。

## 离线交付

解压 release/智汇笔记-完整交付包.zip。面向Windows x64；包内带Python3.11.16运行时，不需要预装Python或Node即可运行已构建网页。运行 ./setup.ps1 -Offline，再运行 ./start-demo.ps1。离线依赖来自offline-wheels，不访问包索引；不得复制原机器.venv。

源码不提交.env、个人数据库、虚拟环境、node_modules和dist；交付ZIP包含dist、wheels、报告、图源和演示材料。打包脚本为scripts/package_release.py，MANIFEST.json列出文件SHA256。任何新增修改必须重新构建、验收、再打包。

## AI配置与实际验收

复制backend/.env.example为backend/.env，填写DEEPSEEK_API_KEY，按账号可用模型设置DEEPSEEK_MODEL；密钥不能进入Git。无Key默认本地。真实验收应显示engine=api；错误Key或屏蔽外网应显示engine=local，页面正常返回。已使用小组Key验证真实摘要和标签，两项均为engine=api，记录见evidence/real-api-test.json。Key仅保存在本机backend/.env，ZIP不携带。

## 验证命令

后端：backend/.venv/Scripts/python.exe -m pytest backend/tests -q。
前端：进入frontend，npm run build、npm run test:e2e；浏览器测试需先运行独立测试或演示服务器，不能指向个人生产库。默认TEST_BASE_URL=http://127.0.0.1:5000，可调整到测试服务。

演示库与.env在Git忽略列表内；截图和自动证据保存在docs/evidence。

## D盘空间约定

把交付包解压到D盘。包内提供独立 Python 3.11.16 运行时（不是原作者的虚拟环境），setup.ps1优先从它新建环境；不需要把Python安装到C盘。pip、npm、uv和临时缓存都写入项目的.tools/cache。运行脚本可用 -Port 5001 指定备用端口。

本机新增Python与Chromium测试浏览器已迁至D:/CodexDependencies，C盘旧入口仅保留目录联接，便于已有环境继续引用。新下载的Node、离线wheel和视频工具全部在D盘。已有系统软件和Codex内置运行时不是本项目安装内容。
