# 智汇笔记 系统设计报告

## 架构与数据

表现层Vue3通过同源fetch访问Flask蓝图。SQLAlchemy负责用户范围内的查询和事务，SQLite保存本地业务数据。前端打包后由Flask托管，Vue history路由在非API的404时回退index.html，API错误返回JSON。

表及关系见 diagrams/智汇笔记.drawio 的E-R页；UML源见 智汇笔记.mdj。核心八表为 user、notebook、note、tag、note_tag、todo、mindmap、bill。既有字段保留，无破坏性迁移。

## 身份与正文

Session保存用户ID并由密钥签名；密码采用已有PBKDF2加盐哈希。查询单个资源时同时验证user_id，他人资源返回404。会话恢复先请求/api/auth/me，前端路由守卫等待该请求。

content_html是新笔记正文；后端用nh3白名单清理，并提取纯文本写入content_md。旧笔记只有content_md时按Markdown渲染供导图和AI读取，前端使用marked兼容打开。HTML保留Quill标题、排版、链接和允许的内嵌位图，删除脚本、事件和不允许的样式。

## 公共接口契约

新增接口成功列表200、创建201、修改或删除200。身份失败401、资源缺失或越权404、输入错误400。错误体为 {error:说明}。所有日期为YYYY-MM-DD；月份YYYY-MM。

| 接口 | 输入及输出 |
|---|---|
| GET /api/todos | 可选note_id、done=0或1；返回待办数组和source_note |
| POST /api/todos | title、可选note_id/due_date/done；返回创建记录 |
| GET/PUT/DELETE /api/todos/{id} | 读取、部分修改或删除本人待办 |
| GET/POST /api/mindmaps | 可选note_id筛选；创建需title和map_json对象 |
| GET/PUT/DELETE /api/mindmaps/{id} | 读取、修改或删除；map_json返回node_tree对象 |
| POST /api/notes/{id}/to-mindmap | 创建新导图；?preview=1只预览而不写数据库 |
| POST /api/ai/summary | {note_id}；返回summary、engine、input_truncated |
| POST /api/ai/tags | {note_id}；返回tags、engine、input_truncated |
| GET/POST /api/bills | 可选month筛选；创建需type、amount、bill_date |
| GET/PUT/DELETE /api/bills/{id} | 读取、部分修改或删除本人记录 |
| GET /api/bills/monthly?month=YYYY-MM | income、expense、balance、daily数组和categories数组 |

source_note为{id,title,is_deleted}或null。建立新关联只能选择本人未删除笔记；既有来源删除后仍允许编辑待办并保留原关联。恢复笔记无需改关联字段。

## 导图算法

根节点使用笔记标题，依次读取h1/h2/h3。维护标题栈：遇到同级或浅级标题弹栈，新节点挂到最近的浅级标题下；跳级不创建空白占位节点。没有标题时只有根节点，页面给出提示。每次生成创建新记录；重新生成已有记录先预览，确认后PUT覆盖。

node_tree必须有合法根节点，节点ID唯一、文字非空，children为数组，最大1000节点和64层。仅保留支持的字段；前端support_html=false，节点文字中的HTML显示为文字。

## AI与金额

本地摘要按句子关键词评分抽取并按原顺序输出，最多约200字；标签按中文词表和英文高频词生成，最多5项。只读取清理后的纯文本，超过10000字符截取并标记。调用DeepSeek /chat/completions，模型由DEEPSEEK_MODEL配置，默认deepseek-flash。

远程调用使用最多4个并发槽，后台线程独立执行；请求等待使用队列8秒上限，HTTP连接与读取分别有超时，不重试。无Key不启动远程线程；槽满直接降级。reason可为no_key、timeout、api_error、invalid_response、api_busy。摘要只展示；用户确认标签后与最新已有标签合并再保存。

账目金额为Numeric(10,2)，输入转换为Decimal，拒绝零、负值、非数字、非有限值、多于两位小数和超范围值。月份查询使用左闭右开日期区间，收入支出结余均在后端计算，图表接收数值，空日期补零。

## 前端状态与生命周期

未保存状态比较标题、HTML、分组和标签。页面离开、模块切换和退出前调用自定义弹窗；标签采用和导图生成先保存。列表及详情分别使用请求序号屏蔽迟到结果。Quill、jsMind、ECharts实例不放入深响应式状态，ECharts显式dispose，jsMind清理容器、拖拽事件和观察器。

## 部署与引用

开发Vite5173代理到Flask5000；交付使用同源Flask和dist。离线包包含Windows x64/Python3.11 wheels；新建虚拟环境，不搬运原作者环境。演示使用demo.db，个人app.db及.env不进入交付包。
