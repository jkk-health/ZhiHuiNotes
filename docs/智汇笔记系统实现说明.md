# 智汇笔记系统实现说明

## 1 项目定位

智汇笔记是面向学生的 Web 个人知识管理系统。当前交付版本把笔记作为核心资料入口，打通笔记、待办、思维导图、轻记账和 AI 助手五个模块。系统支持单用户数据隔离、浏览器本地访问、离线运行以及可选的真实 DeepSeek API 调用。

本文说明当前源码已经实现的功能、使用的工具和技术、核心数据结构、主要实现流程、运行方式与验证结果。社区分享、AI 问答、独立看板、多人协作编辑、OCR 和移动端 App 不属于当前交付范围。

## 2 已实现功能

### 2.1 用户与数据隔离

用户可以注册、登录、退出和刷新恢复会话。后端通过登录装饰器读取当前用户，并在每个业务查询中限制 user_id。未登录请求返回 401，访问不存在或其他用户资源统一返回 404，参数错误返回 400 和 JSON error 字段。密码使用 Werkzeug 哈希保存，不保存明文密码。

### 2.2 富文本笔记

笔记使用 Quill 2.0.2 编辑器，支持标题、字号、加粗、斜体、下划线、删除线、颜色、背景色、引用、代码块、链接和内嵌图片。图片以 data URL 形式嵌入正文，前端限制单张图片不超过 2 MB。

每条笔记保存 title、content_html 和 content_md 两份正文表示。content_html 用于富文本展示；后端使用 nh3 清理 HTML 并提取纯文本写入 content_md，用于搜索、AI 和导图。历史 Markdown 数据仍可通过 marked 兼容打开。笔记支持笔记本分组、标签、置顶、标题和正文搜索、软删除、回收站查看和恢复。

### 2.3 待办联动

待办可以独立存在，也可以通过 note_id 关联一条笔记。用户可创建、修改、完成和删除待办，并从待办跳转到来源笔记；笔记页面也可查看关联待办。笔记移入回收站后，关联待办仍保留，并在界面上标记来源状态。

### 2.4 思维导图

系统可按笔记标题层级生成 jsMind 数据，将标题结构转换为根节点、分支和子节点。导图可独立编辑，支持双击改名、新增子节点、新增同级节点、删除节点、拖拽调整层级、展开/收起、缩放、适应画布、回到中心和全屏编辑。导图以 JSON 存储，编辑结果不会反向修改原笔记正文。

导图编辑器使用 SVG 连线、分支配色和文字换行。新生成且未指定方向的分支自动左右分布，已经保存的手动方向会保留。来源笔记进入回收站时，导图仍可打开。

### 2.5 轻记账与统计

用户可记录收入和支出，填写分类、金额、日期和备注。后端使用 Decimal 处理金额并拒绝负数，前端用 ECharts 展示月度收支趋势和分类汇总。统计按月份查询，空月份也能返回结构化结果。

### 2.6 AI 摘要与标签

AI 功能由 Flask 后端统一代理。配置 DEEPSEEK_API_KEY 后，系统通过 /chat/completions 请求 DeepSeek；未配置密钥、外部请求超时、连接失败、HTTP 错误或返回结构无效时，自动切换本地规则引擎。远程调用设置 8 秒总等待预算，不重试。

摘要先生成预览，用户可复制或手动采用，不会自动覆盖正文。标签先以候选形式展示，用户勾选后再合并到现有标签。AI 只读取清理后的纯文本，超过 10000 字会截取并返回 input_truncated 标记。接口返回 engine 字段，便于区分 api 和 local；本地降级时还会返回 reason。

## 4 系统架构

浏览器首先加载 Vue 单页应用。页面通过同源 fetch 调用 Flask 的 /api JSON 接口。Flask 蓝图负责认证、资源校验和 HTTP 响应；业务服务负责正文规范化、导图转换和 AI 降级；SQLAlchemy 将模型映射到 SQLite。前端构建后由 Flask 直接托管 frontend/dist，Vue Router 的非 API 404 会回退到 index.html。

系统采用八张核心表：user、notebook、note、tag、note_tag、todo、mindmap、bill。用户与各类资源是一对多关系；笔记与标签是多对多关系；待办和导图通过可空 note_id 关联来源笔记。笔记本删除后，笔记保留并归入未分组；用户删除时依靠 SQLite 外键级联清理其数据。

## 5 关键实现

### 5.1 正文双写与安全清理

前端 Quill 产生 HTML 后先经过 DOMPurify；后端再次使用 nh3 白名单清理。后端将清理后的 HTML 提取为纯文本并写入 content_md。这样既保留编辑器格式，又让搜索、AI 和导图读取统一的纯文本。搜索只在 title 和 content_md 上执行 LIKE 查询，避免匹配 HTML 标签。

### 5.2 笔记回收站

删除笔记只将 is_deleted 设为 true，不立即删除数据库记录。普通列表过滤 is_deleted=false，回收站列表过滤 is_deleted=true。恢复接口把标记改回 false。因为 todo 和 mindmap 使用 note_id 且业务层不做级联软删除，来源笔记进入回收站后关联内容仍可使用。

### 5.3 导图生成与保存

后端从清理后的正文中解析标题层级，生成 jsMind node_tree JSON。前端 MindmapEditor 读取 JSON 并初始化 jsMind，使用 SVG 引擎绘制连线。节点编辑、拖拽和布局变化后触发 publish，将最新 node_tree 回传父组件并保存到 mindmap.map_json。导图被定义为笔记的派生视图，因此不回写笔记正文。

### 5.4 AI 适配器与降级

AIService 统一提供摘要和标签方法。若存在密钥，服务向 DeepSeek 发送一次请求并校验返回结构；若失败或超过 8 秒，则调用本地规则引擎。摘要规则引擎按句子关键词评分后按原顺序抽取，长度约 200 字以内；标签引擎按中文词表和英文高频词生成，最多 5 个候选。前端只在用户确认后写入标签。

### 5.5 账号与接口安全

所有业务蓝图都挂在 /api 下。资源访问前先查当前用户和资源归属，越权访问统一返回 404，避免泄露资源是否存在。SQLite 连接时显式打开 PRAGMA foreign_keys=ON。数据库 URI、密钥、模型和 AI 地址从 .env 或环境变量读取，交付包不包含真实 Key。

## 7 运行方式

### 7.1 一键启动

Windows x64 下，将交付包完整解压到普通文件夹，双击“一键启动.bat”。首次启动会准备包内 Python 运行时、离线依赖和演示数据库，然后打开 http://127.0.0.1:5000/login；端口占用时会自动选择 5001 到 5019。演示账号为 demo，密码为 demo123456。双击“停止运行.bat”停止后台服务。

### 7.2 开发运行

后端在 backend 目录创建虚拟环境并安装 requirements.txt，使用 Flask 运行 wsgi.py；前端进入 frontend 执行 npm install 和 npm run dev。开发时 Vite 使用 5173 端口并代理 /api 到 Flask。构建交付执行 npm run build，生成 frontend/dist。

### 7.3 离线运行

完整交付包包含便携 Python 3.11.16、离线 wheels 和已构建前端。执行 setup.ps1 -Offline 后即可启动，不需要预装 Python、Node.js 或联网安装依赖。个人数据库使用 backend/app.db；演示入口使用 backend/demo.db，新增数据会在重启后保留。

## 8 验证结果

当前项目文档记录的验证结果为：扩展后 106 项后端 pytest 通过；导图更新后 14 条 Playwright 浏览器流程通过；Node 20 构建通过；断开外网时本地页面、数据和本地 AI 仍可运行；真实 DeepSeek 摘要和标签调用曾用小组 Key 验证成功，交付包不包含 Key。

自动化测试与人工验收分开记录。人工测试签字、目标电脑复验和答辩彩排仍应由项目成员按最终演示环境执行。测试结果不等同于生产环境或田间场景的准确率结论。

## 9 当前边界

本版本不宣称已经实现社区分享、AI 问答、独立数据看板、多人协作编辑、OCR、移动端 App 和永久删除。导图编辑不会反向改写笔记；AI 摘要不会自动覆盖正文；AI 标签不会未经确认自动写入。真实 API 调用依赖用户自己的 Key 和网络条件，未配置时以本地规则引擎完成演示。
