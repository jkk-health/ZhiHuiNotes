# 智汇笔记

面向学生的Web个人信息管理系统：富文本笔记、关联待办、思维导图、轻记账、AI摘要与标签。五块功能均已实现，后端106项测试通过；2026年10月12日导图更新后，14条浏览器流程通过。真实DeepSeek摘要与标签已用小组Key验证通过；未配置时使用本地规则引擎。交付包不包含Key。

## 快速运行

完整交付包的一键启动：**先完整解压，再双击 `一键启动.bat`**。首次自动离线准备环境和演示数据库，随后在后台启动服务并打开浏览器；无需预装 Python、Node.js 或手动运行 PowerShell。账号 `demo / demo123456`。双击 `停止运行.bat` 停止服务，重启保留已有笔记。默认使用 5000 端口，被占用时自动选择 5001～5019。详细说明见 `一键启动说明.txt`。

环境：Windows x64、Python3.11、Node20。项目根目录运行 `./setup.ps1`，然后 `./start-demo.ps1`，打开 http://127.0.0.1:5000 ，账号 `demo / demo123456`。如Python路径未被识别，可向setup传入 `-Python '完整路径'`。

完整交付ZIP含前端构建产物、Python3.11.16便携运行时和25份离线wheels。解压到D盘后运行 `./setup.ps1 -Offline`，再启动演示；无需预装Python或Node。缓存与临时下载也写入D盘项目目录。

## 功能

笔记支持Quill富文本、内嵌图片、笔记本、标签、标题正文搜索、置顶、软删除和恢复。旧Markdown继续兼容。待办与笔记双向跳转；导图按标题层级生成，可编辑拖拽保存；记账支持月度趋势与分类；AI先预览，标签确认后合并。

导图使用分支配色与SVG曲线，长标题完整换行；支持双击编辑、新增同级、收起展开、全屏、缩放比例、适应画布和回到中心。未指定方向的新导图左右分布，已有手动方向保留。旧导图直接使用新样式，无需重新生成。

笔记移入回收站后，关联内容保留并标记来源状态。社区、AI问答和独立看板延期。

## 文件与验证

`backend/`为Flask REST API，`frontend/`为Vue3，`docs/`为需求文档、图纸与测试截图，`scripts/`为打包与启动辅助。代码按 Conventional Commits 规范提交，经 Pull Request 评审后合入主干。

后端测试：`backend/.venv/Scripts/python.exe -m pytest backend/tests -q`。浏览器测试：先启动独立演示服务，再进入frontend运行`npm run test:e2e`。浏览器测试会创建测试账号，不能指向个人生产库。

演示只使用`backend/demo.db`；`seed.py`拒绝清空`app.db`，已有演示库重置必须传`--reset`。个人数据和密钥不进入交付ZIP。

运行细节见 `一键启动说明.txt`；需求与设计见 `docs/` 下的 Word 文档，图纸源文件在 `docs/diagrams/`。
